# HomeFarm Planner

A web application to help urban residents design and manage their balcony or terrace gardens.

## Features

- Design your garden space with custom dimensions
- Get plant recommendations based on sunlight conditions
- Track plant care and harvesting schedules
- Monitor garden progress

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:3000`

## Technologies

- React
- TypeScript
- Material-UI
- Vite
